# Malaysian Public Data Enrichment Demonstration

Demonstration of a Python-based workflow for preparing and processing Malaysian public registry data for analytical research.

## Overview

This repository contains a small, simplified module derived from my ongoing PhD research in Data Science.

The demonstration shows a Python-based workflow for processing publicly accessible Malaysian registry data and converting unstructured name information into structured analytical output.

It is intended to demonstrate my approach to data preparation, API-based processing, output validation, error handling and checkpointing. It does not represent the complete research methodology or experimental workflow used in my doctoral research.

## Research Context

My doctoral research examines methodological approaches to enriching structurally unavailable demographic attributes in registry-style Business Intelligence data.

The research uses publicly accessible Malaysian tourist guide registry data as its empirical setting.

The code presented here is a simplified version of one module within the broader research workflow. The complete research code and methodology are not publicly disclosed at this stage because the doctoral research is ongoing and remains under preparation for thesis submission and publication.

## Demonstration Workflow

The demonstration covers:

1. Loading CSV data with encoding handling
2. Checking and preparing required data fields
3. Processing records using Python and an API
4. Restricting outputs to predefined categories
5. Handling unexpected responses and processing errors
6. Saving intermediate checkpoints
7. Exporting structured analytical results
