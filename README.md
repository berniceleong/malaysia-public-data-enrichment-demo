# Malaysian Public Data Enrichment Demonstration

## Overview

This repository contains a simplified demonstration derived from
an early stage of my ongoing PhD research in Data Science.

The project demonstrates a Python-based workflow for processing
publicly accessible Malaysian registry data and converting
unstructured name information into structured analytical output.

The repository is intended to demonstrate my approach to data
preparation, API-based processing, validation, error handling,
checkpointing and reproducible analytical workflows.

## Research Context

My doctoral research examines methodological approaches to
enriching structurally unavailable demographic attributes in
registry-style Business Intelligence data.

The research uses publicly accessible Malaysian tourist guide
registry data as its empirical setting.

This repository contains only a simplified demonstration of an
early-stage workflow.

## Workflow

The demonstration covers:

1. Loading CSV data with encoding handling
2. Checking required data fields
3. Processing records using Python and an API
4. Restricting outputs to predefined categories
5. Handling unexpected responses and processing errors
6. Saving intermediate checkpoints
7. Exporting structured analytical results

## Research Status and Scope

This repository does not contain the complete methodology or
dataset used in my doctoral research.

The current research includes additional inference controls,
validation procedures, experimental configurations and evaluation
methods that are not included here because the thesis remains
under preparation.

The full research dataset, manually validated reference data,
lexical resources and unpublished experimental results are also
excluded.
